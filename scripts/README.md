\# Scripts



This directory contains the analysis scripts used for the BRFSS 2023 application.



\## Script order



Run the scripts in the following order:




1\. `01\_download\_brfss\_2023.R`  

&#x20;  Downloads the BRFSS 2023 data.



2\. `02\_prepare\_brfss\_2023.R`  

&#x20;  Cleans and prepares the BRFSS 2023 analysis dataset.



3\. `03\_fit\_brfss\_2023.R`  

&#x20;  Fits the BRFSS 2023 models.



4\. `04\_plot\_brfss\_2023.R`  

&#x20;  Creates figures from the BRFSS 2023 analysis.



\## Notes



\- Scripts are intended to be run from the project root directory.

\- Intermediate outputs should be saved in `results/`.

\- Final figures should be saved in `figures/`.

\- Data documentation is available in `data/data\_dictionary.csv`.
