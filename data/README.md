\# Data



This directory contains data documentation and, when applicable, processed data files used in the analyses.



\## Contents



\- `data\_dictionary.csv`  

&#x20; Describes the variables used in the simulation studies and BRFSS 2023 application.



\## Notes



\- Raw BRFSS 2023 data should not be committed to this repository if the file is large or restricted.

\- Data downloading is handled by `scripts/05\_download\_brfss\_2023.R`.

\- Data preparation is handled by `scripts/06\_prepare\_brfss\_2023.R`.

\- Processed analysis-ready files, if generated, should be documented here.
